## Nguồn sinh

Toàn bộ thư mục này, kể cả tệp README bạn đang đọc, **được sinh tự động** từ
`_nguon/build.py`. Sửa nội dung ở `_nguon/nodes_*.py` rồi chạy `python3 _nguon/build.py`;
sửa tay `.md` hay `.html` ở đây là mất trong lần dựng sau.
